## Particularidades de Claude Code

- `AGENTS.md` es la norma única. No dupliques aquí sus reglas; si hay que cambiar una, cámbiala allí.
- Al empezar, lee `docs/CONTEXTO-LOCAL.md` si existe; no está versionado. Todo lo que queda fuera de este repositorio es de solo lectura: las demostraciones Lean previas, NeuroMIND y los cursos hermanos. Antes de escribir fuera del repositorio, pide autorización explícita.
- Usa el *scratchpad* de la sesión para ficheros temporales, nunca este repositorio.
- Al cerrar cada sesión, entrega un único resumen consolidado: archivos, comprobaciones, hallazgos, decisiones pendientes y un solo siguiente paso. Después, detente.
